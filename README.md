# AnimeDex

AnimeDex é um site de informações sobre personagens de anime. Nele, o visitante pode pesquisar um personagem pelo nome, conhecer sua história, suas habilidades, os animes em que aparece e os dubladores que lhe deram voz, tudo em um só lugar e com uma navegação simples.

## Sobre o projeto

O objetivo do AnimeDex é reunir dados confiáveis e bem organizados sobre personagens de diferentes animes, para que fãs antigos e novos possam consultar, comparar e descobrir novos favoritos. O projeto é feito por fãs e sem fins lucrativos.

## Funcionalidades

O site permite buscar personagens por nome, anime ou característica, e filtrar os resultados por anime, gênero, estúdio e papel na história, como protagonista, vilão ou coadjuvante. Cada personagem tem uma página própria com idade, altura, afiliação, habilidades e resumo da trajetória. Também estão previstos um sistema de favoritos, um comparador entre dois personagens, informações sobre dubladores originais e brasileiros, modo claro e escuro e layout adaptado para celular, tablet e computador.

## Tecnologias

O front-end é construído com HTML, CSS e JavaScript, podendo evoluir para um framework como React.

## Organização das pastas

O código fica dividido em uma pasta public, com imagens e arquivos estáticos, e uma pasta src, que contém os componentes reutilizáveis, as páginas do site, , os estilos globais e as funções auxiliares. A pasta docs guarda a documentação e as imagens usadas neste README.

## Próximos passos

Já estão planejadas a página inicial, a listagem de personagens e a busca por nome. As próximas etapas são os filtros avançados, o sistema de favoritos, o comparador de personagens, as contas de usuário com comentários e a tradução do site para inglês e espanhol.
